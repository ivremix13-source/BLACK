# BLACK — Free Fire Hub

واجهة ويب عربية RTL باستخدام React + Vite، مصممة لتكون أساسًا قابلًا للتوسّع لموقع BLACK.

## المتطلبات
- Node.js إصدار LTS حديث
- npm

## التشغيل محليًا
1. فك ضغط المشروع.
2. افتح مجلد `BLACK-Free-Fire-Platform` في VS Code.
3. افتح Terminal داخل المجلد.
4. نفّذ:

```bash
npm install
npm run dev
```

5. افتح الرابط المحلي الذي يظهر في الطرفية.

## بناء نسخة النشر
```bash
npm run build
npm run preview
```
الملفات الجاهزة للنشر ستظهر داخل مجلد `dist`.

## الموجود في النسخة الأولية
- مقدمة BLACK متحركة.
- صفحة رئيسية بخمس بطاقات قابلة للتنقل.
- قسم حساسية مع البحث عن الجهاز وخيارات أسلوب اللعب.
- قسم رابط تنزيل خارجي.
- قسم HUD مع زر نسخ.
- صفحة تواصل مع واتساب وتيك توك وديسكورد.
- صفحة متجر تعرض «قريبًا».
- زر رجوع، تصميم متجاوب، وحركات تراعي إعداد تقليل الحركة في الجهاز.

## ملاحظات مهمة قبل النشر
- هذه نسخة واجهات أمامية (Frontend) أولية. لا توجد قاعدة بيانات أو لوحة إدارة محمية أو حسابات مستخدمين في هذه النسخة.
- قيم الحساسية أمثلة ابتدائية وليست بيانات مختبرة على كل جهاز؛ يلزم اختبارها وتحديث قاعدة القيم قبل وصفها بأنها مخصصة بدقة.
- الصور والخطوط الخارجية تتطلب اتصالًا بالإنترنت. استخدم أصولًا تملك حق استخدامها عند نشر الموقع.
- تحقق من ملف APK ومصدره قبل التوصية بتثبيته.
- رابط واتساب مبني على الرقم المحلي المقدم مع رمز السودان `249`. تأكد من صحة الرقم الدولي.
- لا تضع مفاتيح سرية أو كلمات مرور داخل كود الواجهة الأمامية.

## الهيكل
- `src/App.jsx`: الصفحات والتنقل والتفاعلات.
- `src/data.js`: أقسام الموقع والأجهزة والقيم الابتدائية.
- `src/styles.css`: الهوية البصرية والتجاوب والحركات.
- `index.html`: إعداد الصفحة الأساسية واللغة العربية واتجاه RTL.

## الخطوة التالية
إضافة Backend آمن وقاعدة بيانات ولوحة إدارة محمية لتعديل الأجهزة وقيم الحساسية وروابط التواصل دون تحرير الكود يدويًا. يمكن استخدام Supabase أو خدمة مماثلة بعد إعداد المشروع وحساباته بشكل آمن.
